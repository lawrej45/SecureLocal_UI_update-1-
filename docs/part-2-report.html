1. Project overview

SecureLocal is a local-first web application for account registration, food ordering, incident reporting, MFA, and role-based administration. The stack is Node.js, Express, EJS, and SQLite. Components are separated by responsibility: route modules, authentication middleware, security helpers, database schema, views, and public assets.

  • Authentication uses bcrypt password hashes, rate limits, lockouts, and optional TOTP MFA.
  • Browser-changing requests require CSRF tokens; order contact details are encrypted at rest.
  • Administrative actions and sensitive views append to a SHA-256 hash-chained audit log.
  • Admin routes require the exact Admin role and fresh MFA. Role checks read current database state.

6. Deployment note

The current setup is intended for local coursework demonstration. For a real deployment, set `NODE_ENV=production`, use HTTPS and unique generated secrets, use a persistent server-side session store, protect and back up the SQLite database, provision roles through an audited process, and do not seed demo users. Keep `.env`, database files, and demo passwords out of source control and submitted archives.
